# MouseSpeedSwitcher（鼠标灵敏度自动切换）

一个轻量的 Windows 后台工具：**识别系统中的鼠标设备，在插入特定鼠标（如轨迹球）时自动切换指针/滚轮速度，拔出时恢复原速度**；还可为规则设备开启「滚轮模式」——按住触发键移动轨迹球即纵向滚动。

例如：你的轨迹球鼠标厂商没提供灵敏度调节，而 Windows 的默认速度对它来说太快。给它的 `VID:PID` 配一条规则后，插入轨迹球 → 自动降到合适速度；拔出 → 自动恢复。

纯 Win32 原生实现（无 GUI 框架、无运行时依赖），单文件 exe 约 235KB，普通用户权限即可运行。

## 特性

- **后台常驻**：无主窗口，隐藏宿主窗口 + 阻塞式 `GetMessageW` 消息循环，空闲时零轮询、零重绘
- **CPU 近乎零开销**：完全事件驱动（`WM_DEVICECHANGE` 设备通知 + 一次性防抖定时器），65 秒无操作累计 CPU 约 31ms
- **内存极低**：空闲总工作集约 10.8MB、私有工作集约 1.2MB、Private Bytes 约 1.7MB、单线程（旧 egui 版工作集约 114MB）。详细数据见 [docs/性能基线.md](docs/性能基线.md)
- **托盘菜单**：自绘菜单内嵌双滑动条——指针速度（1–20）与滚轮速度（1–100 行/齿），拖动中只显示灰色预览、**松手才应用**；标题行附「恢复默认」按钮（指针 10 + 滚轮 3）
- **生效规则三行**：规则名 / 指针·滚轮速度 / 滚轮模式状态（开关、鼠标触发键、键盘触发键、像素/行）
- **设备分区展示**：主菜单只列**有规则**的设备行（名称 + VID/PID，启用滚轮模式的带滚轮图标、当前生效者带对勾）；其余设备收进 **「其他设备 (N)」** 二级子菜单，悬停其中任意一行同样弹出单设备配置面板
- **设备子菜单**：悬停设备行（行右缘 › 指示）弹出配置面板——VID/PID 信息、指针/滚轮双滑块（本地预览、标签实时显示档位）、滚轮模式开关、鼠标触发键与键盘触发键录入（点击后按一下要用的键即录入，Esc 取消）、滚动灵敏度滑块，以及 **「设为规则」** 按钮——调好预览后一键存为该设备的规则；另有「用当前速度保存规则 / 删除此设备规则 / 重新应用规则」三个操作行
- **滚轮速度**：滚轮速度为系统全局设置（Windows 无按设备区分的 API），规则可选带滚轮值：设备插入自动切滚轮、拔出自动恢复
- **滚轮模式（轨迹球特化）**：**按规则单独配置**；生效规则若启用，按住鼠标/键盘触发键时移动即纵向滚轮滚动（指针冻结），松开恢复。位移取自 Raw Input（与钩子吞移动互不影响，无回弹），攒够一齿（像素/行 × 系统每齿行数）经 `SendInput` 注入整齿滚动，每步精确等于系统「每齿行数」。键盘触发为**单键开关**语义——例如按住 `Alt` 时滚动，一旦同时按下其它键（`Alt+Tab` 等）立即取消，不影响系统快捷键；`Win` 键作触发键时，若本次按住期间实际滚动过，释放时注入 `Ctrl` down+up + `Win up`，系统把本次释放识别为 `Win+Ctrl` 组合键序列而不弹 Start 菜单（轻点未滚动则 Start 菜单正常）
- **键盘可操作**：菜单内 `↑`/`↓` 移动焦点、`Enter`/`Space` 激活、`←`/`→` 微调指针速度、`Esc` 关闭
- **主题自适应**：菜单配色跟随系统深色模式与高对比度设置（`WM_SETTINGCHANGE` 时刷新）；Per-Monitor V2 DPI 感知，多显示器不同缩放均正确
- **开机自启**：写 HKCU Run 键，无需管理员权限，托盘菜单可开关
- **单实例**：二次启动静默退出（`MSS_NO_SINGLETON=1` 可跳过，调试用）；Explorer 重启后托盘图标自动恢复（`TaskbarCreated`）
- 技术栈与实现细节见 [docs/技术文档.md](docs/技术文档.md)，历史坑位见 [docs/踩坑记录.md](docs/踩坑记录.md)

## 使用

1. 运行 `mouse-speed-switcher.exe`（托盘出现图标，悬停 tooltip 显示当前指针/滚轮速度与生效规则）。
2. **先把系统指针速度调到普通鼠标（非轨迹球）时的值**。
3. 插入轨迹球。
4. 把系统指针速度调到轨迹球想要的速度。
5. 点击托盘图标（左键或右键均可）弹出菜单，悬停「其他设备 (N)」→ 悬停轨迹球所在行（如 `ELECOM Trackball Mouse`），在弹出的子菜单中点 **用当前速度保存规则**。
6. 完成。之后插入轨迹球自动切到该速度，拔出自动恢复第 2 步的值。

> 已建规则的设备会直接出现在主菜单设备区，无需再进「其他设备」。

其它菜单项：

| 菜单项 | 作用 |
|---|---|
| 指针滑动条 | 拖动只预览（标题变灰），**松手才应用**（1–20） |
| 滚轮滑动条 | 拖动只预览，松手才应用（1–100 行/齿） |
| 恢复默认 | 标题行右侧按钮：指针回 10、滚轮回 3 行/齿 |
| 生效规则区域 | 三行：规则名称 / 指针·滚轮两个速度（规则未指定滚轮显示「保持」）/ 滚轮模式状态 |
| 规则设备行（悬停） | 弹出单设备配置子菜单（见下） |
| 其他设备 (N)（悬停） | 展开二级子菜单列出全部无规则设备，悬停任意行弹出同一个单设备配置子菜单 |
| 单设备配置子菜单 | VID/PID 信息、指针/滚轮双滑块（本地预览）、滚轮模式开关、鼠标触发键、键盘触发键、滚动灵敏度滑块（2–200 像素/行，未启用时置灰）+「设为规则」+ 用当前速度保存规则 / 删除此设备规则 / 重新应用规则 |
| 开机自启 | 开关登录自启动（点击后菜单保持打开） |
| 退出 | 退出程序（已应用的速度保持不动） |

菜单关闭方式：Esc、点击菜单外任意处、或执行某个设备规则操作后自动关闭；关闭后前台焦点自动归还之前使用的窗口。

## 配置文件

位于 `%APPDATA%\MouseSpeedSwitcher\config.json`，由托盘菜单自动维护，也可手改：

```json
{
  "rules": [
    {
      "vid": "056E",
      "pid": "01C5",
      "speed": 4,
      "wheel": 9,
      "scroll": {
        "enabled": true,
        "trigger": "x1",
        "kb_trigger": { "vk": 164 },
        "px_per_line": 15
      },
      "note": "ELECOM 轨迹球"
    }
  ]
}
```

- `vid` / `pid`：设备硬件 ID 中的 4 位十六进制（大小写不敏感）。可通过托盘菜单查看每个设备的 VID/PID，或运行 `diag.exe` 查看全部设备。
- `speed`：Windows 指针速度滑块档位（1–20，默认 10）。
- `wheel`：可选，插入该设备时同时应用的滚轮速度（1–100 行/齿）；缺省或 `null` = 规则不改滚轮。
- `scroll`：可选，**该规则专用的滚轮模式配置**。`enabled` 开关；`trigger` 为鼠标触发键（`left` / `middle` / `right` / `x1` / `x2` 之一）；`kb_trigger` 为键盘触发键（`{ "vk": 164 }` 表示 `Alt`，`91` 表示 `Win`，左右 Shift/Ctrl/Alt/Win 会归一化为同一键），单独按住该键进入滚轮模式，一旦又按下其它键立即取消；`px_per_line` 为灵敏度（2–200 像素/行，即轨迹球滚动多少像素 = 滚动一行，值越小越灵敏；旧字段 `px_per_notch` 兼容读取）。缺省 = 该规则不带滚轮模式。
- `note`：备注，仅用于标识。

## 工作原理

- **设备监听**：`RegisterDeviceNotificationW` 注册鼠标接口通知（`GUID_DEVINTERFACE_MOUSE`），`WM_DEVICECHANGE` 触发 350ms 一次性防抖后做一次全量 SetupAPI 枚举（`GUID_DEVCLASS_MOUSE`）并与应用状态对账，处理插入/拔出差异。无后台轮询线程。
- **设备识别**：从硬件 ID（如 `HID\VID_056E&PID_01C5&MI_00`）解析 VID/PID；设备实例 ID 用于区分同型号多设备。
- **速度切换**：`SystemParametersInfo(SPI_SETMOUSESPEED)`，值通过 `pvParam` 传递（`uiParam` 必须为 0）；滚轮速度用 `SPI_SETWHEELSCROLLLINES`（值经 `uiParam` 传递）。均带 `SPIF_UPDATEINIFILE | SPIF_SENDCHANGE`，只更新会话内滑块值，**不会改动**注册表中的增强指针精度配置。
- **恢复策略**：每个规则设备插入瞬间记录当时的指针/滚轮速度，拔出时若无其它规则设备则恢复该值；若有则应用最后插入的规则设备的速度（其规则未指定滚轮时滚轮保持现状）。
- **滚轮模式**：常驻 `WH_MOUSE_LL`（+按需 `WH_KEYBOARD_LL`）低级钩子 + Raw Input（`RIDEV_INPUTSINK` 后台收 `WM_INPUT`）位移源；钩子回调内**绝不** `SendInput`（会自锁 win32k），滚动量先累积再投递 `WM_APP_SCROLL_INJECT`，在普通消息处理上下文里统一注入。菜单打开期间滚轮模式整体放行。
- **UI**：原生 Win32 自绘菜单（GDI 双缓冲 + 真 Trackbar 滑块 + DWM 圆角/暗色主题），系统托盘 `Shell_NotifyIconW`，`WM_SETTINGCHANGE` 时同步滑块/tooltip/主题。详见 [docs/技术文档.md](docs/技术文档.md)。

## 已知限制

- **蓝牙鼠标**：部分蓝牙 HID 设备的硬件 ID 不含 VID/PID（形如 `BTHENUM\...`），无法按 VID/PID 匹配规则，设备行会显示 `VID:---- PID:----`，其子菜单中的规则操作项禁用。
- 指针速度与滚轮速度都是系统全局设置，无法按设备实时区分，因此规则基于「插入/拔出」事件切换；两个带规则设备同时插入时，后插入者生效，拔出后回退到剩余规则或插入前值。
- Windows 11 默认把新应用的托盘图标收进任务栏「溢出区」（^ 图标内），可手动拖出到常显区。
- **滚轮模式**：按生效规则启用，无全局开关；低级钩子在管理员权限窗口中收不到输入（除非本程序也以管理员运行）；滚轮模式的位移取自 Raw Input，在直读 RawInput/DirectInput 的游戏里按住触发键会与游戏视角/输入叠加（注入的滚轮多数游戏不响应），建议游戏前给对应规则关闭。菜单打开期间滚轮模式自动放行。键盘触发为「单键开关」语义：单独按住才生效，同时按下其它键立即取消，避免干扰系统/应用组合快捷键。`Win` 键作为触发键时，Win 释放时会注入左 Ctrl（scan 0x1D）down + up + `Win up`，让系统把本次 Win 释放识别为 `Win+Ctrl` 组合键序列，不弹出 Start 菜单，Win 键也不会卡死。
