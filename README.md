# MouseSpeedSwitcher（鼠标灵敏度自动切换）

## 主要功能

Windows 后台小工具：为单个鼠标（尤其是轨迹球）自动切换灵敏度——插入即切换指针/滚轮速度，拔出即恢复；当多个有规则的设备同时连接时，主菜单中单击目标设备即可手动切换到对应规则；支持给每个规则设置**别名**（在设备子菜单里编辑，替代设备名显示）；支持滚轮模式，按住触发键移动轨迹球即可纵向滚动。

## 软件特点

Win32 原生单文件 exe，约 235KB，无运行时依赖。完全事件驱动，CPU 近乎零开销；空闲 Private Bytes 约 1.7MB，工作集约 10.8MB。

## 使用说明

运行 exe，插入目标鼠标；右键托盘图标 → 悬停「其他设备」→ 目标设备 →「用当前速度保存规则」。之后插入/拔出自动切换。
