# MouseSpeedSwitcher（鼠标灵敏度自动切换）

一个轻量的 Windows 后台工具：**识别系统中的鼠标设备，在插入特定鼠标（如轨迹球）时自动切换指针速度，拔出时恢复原速度**。

例如：你的轨迹球鼠标厂商没提供灵敏度调节，而 Windows 的默认速度对它来说太快。给它的 `VID:PID` 配一条规则后，插入轨迹球 → 自动降到合适速度；拔出 → 自动恢复。

## 特性

- **后台常驻**：无主窗口、无运行时依赖，单文件 exe，普通用户权限即可运行
- **CPU 近乎零开销**：完全事件驱动（`WM_DEVICECHANGE` 设备通知），空闲时阻塞在消息循环，60 秒无操作 CPU 时间约 30ms 以内
- **内存极低**：原生 Win32 实现，空闲工作集约 10MB、私有工作集约 1MB（旧 egui 版约 114MB）
- **托盘菜单**：内嵌双滑动条——指针速度（1–20）与滚轮速度（1–100 行/齿），拖动中只显示预览、**松手才应用**；列出所有鼠标设备（名称 + VID/PID），带规则的设备行标注 `· 规则 N`，当前生效者画对勾；菜单顶部标明生效规则。一键「用当前速度保存规则」「删除规则」「重新应用规则」，无需手改配置
- **设备子菜单**：悬停设备行弹出子菜单，内含**指针/滚轮双滑块（本地预览，标签实时显示档位）+「设为规则」按钮**——拖到期望档位后一键存为该设备的规则
- **滚轮速度**：滚轮速度为系统全局设置（Windows 无按设备区分的 API），规则可选带滚轮值：设备插入自动切滚轮、拔出自动恢复
- **滚轮模式（轨迹球特化）**：按住触发键（默认鼠标侧键1）时移动即纵向滚轮滚动（指针冻结），松开恢复——给滚轮难用或没有滚轮的轨迹球补上顺手的滚动；触发键可录入任意鼠标键，灵敏度（像素/齿）可调，托盘菜单中开启
- **开机自启**：写入 HKCU Run 键，无需管理员权限，托盘菜单可开关
- 技术栈与实现细节见 [docs/技术文档.md](docs/技术文档.md)

## 使用

1. 运行 `mouse-speed-switcher.exe`（托盘出现图标）。
2. **先把系统指针速度调到普通鼠标（非轨迹球）时的值**。
3. 插入轨迹球。
4. 把系统指针速度调到轨迹球想要的速度。
5. 点击托盘图标（左键或右键均可）弹出菜单，悬停轨迹球所在设备行（如 `ELECOM Trackball Mouse`），在弹出的子菜单中点 **用当前速度保存规则**。
6. 完成。之后插入轨迹球自动切到该速度，拔出自动恢复第 2 步的值。

其它菜单项：

| 菜单项 | 作用 |
|---|---|
| 指针滑动条 | 拖动只预览，**松手才应用**（1–20）；「恢复默认」回到 10 |
| 滚轮滑动条 | 拖动只预览，松手才应用（1–100 行/齿） |
| 滚轮模式（勾选行） | 开/关「按住触发键移动 = 纵向滚轮」 |
| 触发键 | 点击后按下的下一个**菜单外**鼠标键成为触发键（点菜单内任意处取消录入） |
| 滚动灵敏度滑动条 | 轨迹球滚动多少像素 = 一齿滚轮（5–200 像素/齿，越小越灵敏，默认 40） |
| 设备行（悬停） | 弹出子菜单：指针/滚轮双滑块（本地预览、标签显示档位）+「设为规则」、用当前速度保存规则 / 删除此设备规则 / 重新应用规则 |
| 开机自启 | 开关登录自启动 |
| 退出 | 退出程序（已应用的速度保持不动） |

菜单关闭方式：Esc、点击菜单外任意处、或执行某个设备规则操作后自动关闭。

## 配置文件

位于 `%APPDATA%\MouseSpeedSwitcher\config.json`，由托盘菜单自动维护，也可手改：

```json
{
  "rules": [
    {
      "vid": "056E",
      "pid": "01C5",
      "speed": 4,
      "wheel": 9,
      "note": "ELECOM 轨迹球"
    }
  ],
  "scroll": {
    "enabled": false,
    "trigger": "x1",
    "px_per_notch": 40
  }
}
```

- `vid` / `pid`：设备硬件 ID 中的 4 位十六进制（大小写不敏感）。可通过托盘菜单查看每个设备的 VID/PID，或运行 `diag.exe` 查看全部设备。
- `speed`：Windows 指针速度滑块档位（1–20，默认 10）。
- `wheel`：可选，插入该设备时同时应用的滚轮速度（1–100 行/齿）；缺省或 `null` = 规则不改滚轮。
- `note`：备注，仅用于标识。
- `scroll`：滚轮模式配置（旧配置缺失时用默认值 = 关、侧键1、40 像素/齿）。`enabled` 总开关；`trigger` 为 `left` / `middle` / `right` / `x1` / `x2` 之一；`px_per_notch` 为灵敏度（5–200 像素/齿）。

## 工作原理

- **设备监听**：后台线程每 2 秒用 `SetupAPI` 枚举鼠标设备类（`GUID_DEVCLASS_MOUSE`）并与应用状态对账，处理插入/拔出差异。
- **设备识别**：从硬件 ID（如 `HID\VID_056E&PID_01C5&MI_00`）解析 VID/PID；设备实例 ID 用于区分同型号多设备。
- **速度切换**：`SystemParametersInfo(SPI_SETMOUSESPEED)`，值通过 `pvParam` 传递（`uiParam` 必须为 0），带 `SPIF_UPDATEINIFILE | SPIF_SENDCHANGE`。此 API 只更新会话内的滑块值，**不会改动**注册表中的增强指针精度配置。
- **恢复策略**：每个规则设备插入瞬间记录当时的指针/滚轮速度，拔出时若无其它规则设备则恢复该值；若有则应用最后插入的规则设备的速度（其规则未指定滚轮时滚轮保持现状）。
- **设备监听**：`RegisterDeviceNotificationW` 注册鼠标接口通知，`WM_DEVICECHANGE` 触发 350ms 防抖后一次全量枚举对账。
- **UI**：原生 Win32 自绘菜单（GDI 双缓冲 + 真 Trackbar 滑块 + DWM 圆角/暗色主题），系统托盘 `Shell_NotifyIconW`。详见 [docs/技术文档.md](docs/技术文档.md)。

## 已知限制

- **蓝牙鼠标**：部分蓝牙 HID 设备的硬件 ID 不含 VID/PID（形如 `BTHENUM\...`），无法按 VID/PID 匹配规则，托盘菜单中会显示 `VID:---- PID:----` 并禁用规则项。
- 指针速度与滚轮速度都是系统全局设置，无法按设备实时区分，因此规则基于"插入/拔出"事件切换；两个带规则设备同时插入时，后插入者生效，拔出后回退到剩余规则或插入前值。
- Windows 11 默认把新应用的托盘图标收进任务栏「溢出区」（^ 图标内），可手动拖出到常显区。
- **滚轮模式**：低级钩子在管理员权限窗口中收不到输入（除非本程序也以管理员运行）；游戏用 RawInput/DirectInput 直读鼠标、绕过钩子，游戏内无效。菜单打开期间滚轮模式自动放行。
