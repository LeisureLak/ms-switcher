# 性能基线与采样口径

> 采集日期：2026-09-06，用于「现代原生低开销架构迁移」阶段 0 的迁移前基线。
> 机器：12 逻辑核，Windows 11，正常桌面会话，Release 构建（`cargo build --release`）。
> 采样脚本：PowerShell `Get-Process` + `Win32_PerfFormattedData_PerfProc_Process`，采样时不启用
> 调试日志、不接调试器、不设置 `MSS_DEBUG_MENU` / `MSS_DEBUG`。

## 指标口径

| 指标 | 来源 |
|---|---|
| 总工作集 Working Set | `Get-Process` `WorkingSet64` |
| 私有工作集 Working Set - Private | `Win32_PerfFormattedData_PerfProc_Process.WorkingSetPrivate` |
| Private Bytes | `Get-Process` `PrivateMemorySize64` |
| 峰值工作集 | `Get-Process` `PeakWorkingSet64` |
| 线程数 | `Get-Process` `Threads.Count` |
| 句柄数 | `Get-Process` `HandleCount` |
| 累计 CPU | `Get-Process` `TotalProcessorTime`，固定时间窗内做差 |

注意：x64 下 ~4GB 的虚拟地址保留量不算内存；禁止用 `EmptyWorkingSet` 等 trim 手段美化数据。

### 内存构成参考（历史实测，见迁移计划第 1 节）

- 最小空 eframe + glow：工作集 77.78MB / 私有 39.77MB。
- 完整程序禁用微软雅黑：工作集 80.25MB / 私有 40.90MB。
- 完整程序加载微软雅黑：工作集 120.50MB / 私有 79.57MB。
- 即：eframe/winit/GL/驱动 ≈ 78MB 固定底噪，整份 msyh.ttc + egui 字体缓存 ≈ +40MB，业务状态仅 1–3MB。

## 迁移目标（硬性验收门槛）

- 启动空闲 60 秒总工作集 < 50MB；菜单打开稳定后 < 50MB。
- 连续开关菜单 20 次后 Private Bytes 增长 < 2MB。
- 优化目标：空闲私有工作集 ≤ 10MB、Private Bytes ≤ 20MB、菜单打开私有工作集 ≤ 25MB。
- 60 秒无操作累计 CPU < 100ms；无固定频率轮询（防抖一次性 timer 除外）。
- 菜单开关 100 次后 GDI / USER Objects 不持续增长；设备插拔 20 次后线程/句柄稳定。

## 迁移后实测（2026-09-06，现代原生 Win32 架构）

### 空闲（启动后静置 65 秒，无用户操作）

| 指标 | 迁移前 | 迁移后 | 门槛 |
|---|---:|---:|---|
| 总工作集 | 114.01 MB | **10.78 MB** | < 50MB（目标 ≤10MB 私有）✅ |
| 私有工作集 | 78.41 MB | **1.20 MB** | 目标 ≤ 10MB ✅ |
| Private Bytes | 102.05 MB | **1.67 MB** | 目标 ≤ 20MB ✅ |
| 线程数 | 9 | **1** | 稳定不增长 ✅ |
| 句柄数 | 298 | 156 | — |
| 65 秒累计 CPU | 2672 ms | **31 ms** | < 100ms ✅ |

### 菜单打开（开关 20 次后采样）

| 指标 | 迁移前 | 迁移后 | 门槛 |
|---|---:|---:|---|
| Private Bytes | 110.37 MB | **2.31 MB** | < 50MB（目标 ≤25MB 私有）✅ |
| 私有工作集 | 86.59 MB | **1.72 MB** | ✅ |

### 菜单开关泄漏

- 开关 20 次 → 100 次：Private Bytes 增长 **0.06 MB**（门槛 < 2MB）✅；句柄 198 → 199（噪声级）✅。
- 100 次悬停进出子菜单循环（25ms 间隔）：无死锁、无闪退、无孤儿窗口 ✅。

### 功能验收记录（自动化部分）

- ✅ 单实例：二次启动静默退出。
- ✅ 配置 JSON 损坏：回退默认配置，不崩溃。
- ✅ WM_DEVICECHANGE 防抖：连发两条广播只触发一次扫描。
